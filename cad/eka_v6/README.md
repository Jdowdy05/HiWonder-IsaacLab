# HiWonder Eka V6 repaired exports

The original STEP is preserved unchanged in the runtime asset directory. These
repaired printable exports retain thirteen imported STEP solids and replace two
invalid cap surfaces with closed, valid faceted solids. No Fusion sketches or
parametric history were recovered. Both the native file and reimported STEP were
checked: fifteen valid solids, positive cap volumes.

The mounted preview contains247 actual final USD mesh components, including
reference motors/horns/bearings and the retained wrist camera. It was saved and
reopened; it is an inspection mesh assembly rather than native parametric CAD.

Mount alignment uses measured matching four-hole14mm pitch circles. Physical
fastener fit, motion clearances, strength, servo calibration and the new physical
camera attachment remain unqualified. Simulation receipts are documented in
source/isaaclab_hiwonder/EKA_V6_VALIDATION.md in the repository.
